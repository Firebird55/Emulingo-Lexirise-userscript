Emulingo Lexirise

Readings, word lookups and language settings on Emulingo, powered by your Lexirise account. Fits mobile and desktop layouts.

Install latest public version

Install a userscript manager first, then open the install link and review its permissions. Your manager checks for updates according to its settings. Existing private/local installs require one manual reinstall to adopt this channel. See installation guide for browser and Safari/mobile limitations.

From an extracted installer bundle, you can also install the bundled version. You do not need local game files, Node.js or a GitHub login to use the public install link.

Connect safely

Open Lexirise settings within Emulingo to enter your key. It stays in userscript-manager storage. Requested text is sent directly to Lexirise; account changes are uploaded only when you press Save to Lexirise. Never paste keys into issues or chat.

Contributing with an AI agent

Read AGENTS.md, CONTRIBUTING.md and RELEASE.md. Use a task branch and GitHub noreply email. Commit each completed logical change; run types, tests, desktop/mobile and Firefox checks and the public privacy audit before pushing. Mock account writes and preserve native game behavior.

Do not edit generated shared package copies. Propose shared changes to the maintainer for the canonical source repository. Release through the documented command and verify hosted assets. No Argo or cluster is required.
